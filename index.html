🚄 新幹線 運行状況チェッカー

公式リンク方式

全新幹線の運行状況。フィード連携ONなら各線の状況を表示、OFFなら公式リンクのみ。

一次情報は各鉄道会社の公式サイトです。 フィードは Yahoo!路線情報を1日数回スクレイピングした目安で、遅延あり。必ず公式で最終確認してください。

フィードの仕組み：scraper/scrape.py を GitHub Actions が定期実行し status.json を更新 → ⚙設定でそのURLを登録。詳細は README。

設定 — 運行情報フィード

GitHub リポジトリに同梱の scraper/scrape.py を GitHub Actions が定期実行して status.json を更新します。その raw URL をここに登録すると、各路線の運行状況が表示されます。 未登録でも公式サイトへのリンクは常に表示されます。

※ raw.githubusercontent.com は CORS 対応のためブラウザから直接読めます。 GitHub Pages や自前サーバーの静的JSONでも可（CORS許可が必要）。
